# OCR models

PP-OCRv6 tiny detection/recognition models and dictionary, converted to ONNX by
[oar-ocr](https://github.com/GreatV/oar-ocr) from the official PaddleOCR models.

- `pp-ocrv6_tiny_det.onnx`
- `pp-ocrv6_tiny_rec.onnx`
- `ppocrv6_tiny_dict.txt`

Source: <https://github.com/GreatV/oar-ocr/releases/tag/v0.7.0>
